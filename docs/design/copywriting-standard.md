# Copywriting Standard

## 1. Scope

Applies to:

- Public Site
- Dashboard
- Agent Workbench
- Empty State
- Loading State
- Error State
- Confirmation
- Receipt
- Navigation
- Buttons
- Inspector

---

## 2. Rules

- 不写产品介绍型文案
- 不写宣传型文案
- 不写愿景型文案
- 不写过度解释型文案
- 优先使用状态、动作、对象、结果
- UI 文案使用短句
- Agent 状态文案必须对应结构化状态
- 不使用泛化表达

---

## 3. Avoid

- 欢迎来到
- 这是一个
- 致力于
- 帮助你
- 开启你的
- 让 AI 赋能
- 打造属于你的
- 第二大脑
- 智能化平台
- 高效管理你的全部人生

---

## 4. Preferred

Navigation:

- Home
- Blog
- Notes
- Timeline
- About
- Writing
- Plans
- Checklist
- Schedule

Status:

- Draft
- Published
- Archived
- Pending Confirmation
- Dry-run Passed
- Policy Blocked
- Receipt Recorded
- Rollback Available
- Conflict Detected

Actions:

- Create draft
- Preview
- Publish
- Unpublish
- View public page
- Review
- Confirm
- Cancel
- Rollback

Empty states:

- No drafts
- No published posts
- No notes
- No timeline events
- No pending actions

---

## 5. Agent Copy

Allowed:

- Understanding request
- Reading context
- Classifying intent
- Drafting
- Running dry-run
- Checking policy
- Waiting for confirmation
- Executing
- Receipt recorded
- Rollback available
- Failed

Avoid:

- 我正在思考
- 我的推理过程是
- 我可以帮你完成一切
- 正在智能分析你的全部数据
- raw chain-of-thought style text
