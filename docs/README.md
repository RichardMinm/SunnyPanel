# SunnyPanel Design Pack

## 文件范围

- `product-map.md`：产品范围、模块、路由、边界
- `feature-index.md`：功能优先级与 Not in v1
- `agent-workflow-v1.md`：Agent 工作流契约
- `safety-model.md`：安全写入边界
- `system-architecture.md`：系统架构边界
- `design/*`：设计规格、状态、生命周期、UI 规范
- `features/*`：单功能规格
- `prompts/*`：Claude Code / Codex 执行提示词

## 文档风格规则

- 不写产品介绍型文字
- 不写宣传型文字
- 不写愿景型文字
- 使用范围、规则、职责、流程、状态、数据关系、禁止事项
- 用于 VibeCoding 前置约束
